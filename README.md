# MoodDo (ムードゥー) 🎨✨

> **「今日の気分は、どんな色？」**  
> タスクに追われる日々に、感情の寄り添い（エモーショナルデザイン）を。あなたの心のリズムに合わせてUI・演出・応援メッセージがリアルタイムに変化する、新感覚のエモーショナルTodoアプリケーションです。

---

## 🌟 コアコンセプト

日々のタスク管理は、時に義務感やプレッシャーをもたらします。  
**MoodDo** は、毎朝の「ムード・チェックイン」からスタート。選んだ気分に応じて、色彩、フォント、完了アニメーション、さらにはタスクへの向き合い方までアプリ全体が丸ごと変化し、あなたのコンディションに優しく寄り添います。

## 🚀 主な機能

1. **朝のムード・チェックイン**: 1タップで感情をセレクト。瞬時にアプリ全体のトーンが同期。
2. **エモーショナル・チアリング**: 気分に合わせた励ましメッセージがメインカードに常時寄り添う。
3. **シームレスなタスク管理**: 直感的なタスク追加・完了トグルと、心地よいマイクロインタラクション。
4. **アダプティブUI**: Tailwind CSS と React による滑らかな背景・カードのグラデーション遷移。
