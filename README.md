# MoodDo (ムード・ドゥ) 🌿⚡🌌

> **「タスクをこなすだけでなく、その瞬間の心に寄り添う。」**  
> MoodDo は、その日の気分に合わせてUI全体のカラー・フォント・アニメーション・メッセージがガラリと変化する、新感覚のエモーショナルTodoアプリケーションです。

---

## ✨ 特徴 & 気分テーマ

ワンタップでアプリの表情がトランスフォーム。あなたのコンディションに最適化された体験を提供します。

| 気分テーマ | トーン＆マナー | 完了時の演出・エール |
| :--- | :--- | :--- |
| **⚡ Energetic（活発）** | サンセットオレンジ / 高コントラスト / 力強いシャープ | 「最高！その調子🚀」「圧倒的スピード！🔥」 |
| **🌿 Relax（のんびり）** | フォレストグリーン / やわらかな丸み / 有機的余白 | 「一歩前進！えらいね🌱」「のんびりクリア🍵」 |
| **🌌 Deep Focus（集中）** | ミッドナイトネイビー / 等幅フォント / 極限シンプル | 「TASK DONE. 集中力持続中✨」「CLEAR. 順調だ。💻」 |
| **☕ Cozy Cafe（カフェ）** | ウォームラテ / モカブラウン / 温かみあるペーパー感 | 「お疲れさま！少し休憩しよう🍪」「いいペースだね📖」 |
| **🌸 Gentle（癒やし）** | サクラピンク / ラベンダー / ドリーミーシャドウ | 「えらい！本当に頑張ってるよ🌸」「自分に花丸をあげよう💮」 |

## 🚀 クイックスタート

外部依存ゼロ。HTMLファイルをそのままブラウザで開くだけで即座に動作します。

1. 本リポジトリの `index.html` をダウンロード。
2. お好きなブラウザでダブルクリックして起動。
3. 気分を選んで、今日の一歩を記録しましょう。

- **Vanilla JavaScript**: 状態管理・LocalStorageによる永続化・トーストアニメーション制御
